KubeDrill package repositories

Local Kubernetes simulator: practice kubectl without a cluster. Source, documentation and issues: github.com/itdrills/kubedrill.

Debian / Ubuntu (apt)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://itdrills.github.io/kubedrill/gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubedrill.gpg
echo "deb [signed-by=/etc/apt/keyrings/kubedrill.gpg] https://itdrills.github.io/kubedrill/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/kubedrill.list
sudo apt update && sudo apt install kubedrill

Fedora / RHEL / Rocky / Alma (dnf)

sudo curl -fsSL -o /etc/yum.repos.d/kubedrill.repo https://itdrills.github.io/kubedrill/kubedrill.repo
sudo dnf install kubedrill

macOS (Homebrew)

brew install itdrills/tap/kubedrill
